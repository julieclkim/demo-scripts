Authorize secure collection

Agent instruction: Ask the student to complete payment details in the secure flow. Do not ask the student to say card, CVV, or bank information aloud.

  • Recording and monitoring should be paused or isolated by the Genesys secure flow.
  • The agent can see amount, payment date, and confirmation status only.
  • No card or bank account values are stored in GitHub Pages or this demo page.

Live-call checklist

  • Verify student identity before starting payment.
  • Click Collect Payment to request secure flow handoff.
  • Confirm amount and payment date with the student.

Payment call flow

Use this path while the embedded script is open.

Step Agent action Demo automation
1 Confirm identity using student ID and contact details. 123456, (555) 010-1010
2 Click Collect Payment and move the call into secure collection. Sets secure flow requested status and opens admin payment portal.
3 Confirm amount, date, and method without collecting card details verbally. Calculates payment confirmation and remaining balance.
4 Submit payment and send SMS confirmation to the student. Generates SMS payload for a Genesys Data Action or Architect SMS step.

Demo data is populated from URL query parameters or data/students.json. The payment portal is for demo workflow only and must not collect real card or bank information.
